# Open data license and scientific provenance

`sensor_measurements.csv` is an original reproducible synthetic teaching dataset, released under **CC0 1.0** (https://creativecommons.org/publicdomain/zero/1.0/). It is generated by `python -m tedkf.simulation` using a 4D thermal-state system and 10 virtual sensors. It includes deliberately injected bias, drift, noise, or stuck-at errors for evaluating research algorithms.

These are **not actual natural gas pipeline pressure, temperature or flow measurements**, nor real utility customer data. The source paper **Trust-Enhanced Distributed Kalman Filtering for Sensor Fault Diagnosis in Sensor Networks**, IEEE TSIPN (2025), DOI: 10.1109/TSIPN.2025.3606167, uses a linear thermal system in its experiments. We implement and document an independent example; no IEEE copyrighted paper text or figures are redistributed.
